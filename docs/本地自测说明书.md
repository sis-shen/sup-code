 # 本地自测说明书
 
 ## 1. 环境要求
 
 | 工具 | 最低版本 | 检查命令 |
 |------|---------|---------|
 | Go | 1.22 | `go version` |
 | golangci-lint | 1.59 | `golangci-lint --version` |
 | Git | 2.30 | `git --version` |
 | GoReleaser（仅 Phase 3） | 2.x | `goreleaser --version` |
 
 安装缺失工具：
 ```bash
 go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest
 go install github.com/goreleaser/goreleaser/v2@latest
 ```

 ## 2. 自测速查（提交前必跑）
 
 每次提交前至少执行前 4 步，全部通过再 push。
 
 ```bash
 # 1. 编译检查
 go build ./...
 
 # 2. 格式化 + import 整理
 gofmt -w . && goimports -w .
 
 # 3. 静态分析
 go vet ./...
 golangci-lint run ./...
 
 # 4. 全量单元测试（含竞态检测）
 go test ./... -count=1 -race
 
 # 5. 架构合规检查（集成阶段）
 bash scripts/check_arch.sh
 
 # 6. 覆盖率报告
 go test ./... -coverprofile=coverage.out
 go tool cover -func=coverage.out | tail -1
 ```

 ## 5. Mock 测试指南
 
 所有 Agent 的单元测试不应依赖真实外部服务。使用以下 mock 策略：
 
 | 依赖 | Mock 方式 |
 |------|----------|
 | LLM API（OpenAI/Claude/DeepSeek） | `httptest.Server` 返回预设响应 |
 | MCP 外部进程 | `httptest.Server` 模拟 JSON-RPC |
 | Git CLI（Worktree） | 临时 `git init` 仓库 |
 | SQLite | 内存数据库（`:memory:`） |
 | 文件系统 | `t.TempDir()` 临时目录 |
 | `exec.Command`（git/npm） | 替换 `execCommand` 函数 |
 | Bubble Tea 终端 | `tea.WithoutRenderer()` |
 | Embedding API | `httptest.Server` 返回固定向量 |

 ## 6. 常见自测问题
 
 ### Q1：`go test -race` 报 "race detected"
 
 原因：并发访问未加锁。检查该包中 `map` / `slice` 的读写是否都有 `sync.RWMutex` 保护。
 
 ### Q2：覆盖率离门禁差几个百分点
 
 运行 `go test ./packagename/... -coverprofile=cover.out && go tool cover -func=cover.out`，找到 0% 覆盖的函数，优先写这些函数的测试。
 
 ### Q3：golangci-lint 报 `undefined` 或 `unused`
 
 `gofmt -w . && goimports -w .` 通常能修复。如果仍有误报，在代码中使用 `//nolint:unused` 注释。
 
 ### Q4：`scripts/check_arch.sh` 报错
 
 检查是否在 `internal/tools` 中 import 了 `internal/agent`，或在 `pkg/` 中 import 了 `internal/`。架构规则见 [系统架构设计说明书](系统架构设计说明书.md) 第 6 节。
 
 ### Q5：TUI 测试在 CI 中失败
 
 Bubble Tea 测试需要 `tea.WithoutRenderer()` 选项，否则在没有终端的 CI 环境中会 panic。
 
 ### Q6：MCP / Skill 测试依赖真实外部进程
 
 不应依赖。MCP 用 `httptest.Server`，Skill 的 `InstallFromGit` 用 `exec.Command` mock（参考 `TestFakeExecHelper` 模式）。

 ## 7. 自测脚本一览
 
 ```bash
 scripts/
   lint.sh                # golangci-lint run ./...
   test.sh                # go test -race -count=1 ./...

   build.sh               # 全平台交叉编译
   check_arch.sh          # 架构合规检查
   bench.sh               # 启动时间 + 二进制大小
 ```

 ## 8. 提交前检查清单
 
 逐项勾选后再提交代码：
 
 - [ ] `go build ./...` 编译通过
 - [ ] `go test ./... -count=1 -race` 0 failure
 - [ ] 所属包覆盖率 >= 门禁要求
 - [ ] `golangci-lint run ./...` 0 issue
 - [ ] `bash scripts/check_arch.sh` 通过
 - [ ] 无未使用的 import（`goimports -l .` 为空）
 - [ ] 新增公开函数有 godoc 注释
 - [ ] 提供了对应的 Mock 实现（如适用）
